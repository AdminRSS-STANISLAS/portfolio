// 02 — Projets

Ce que j'ai livré

Projet principal

FKC Scoring — arbitrage de compétitions de karaté

Plateforme complète de gestion et d'arbitrage de tournois (Kumite et Kata) : inscriptions, génération automatique des tableaux, chronométrage, scoring en direct, classements et exports PDF/Excel.

La contrainte structurante : fonctionner sans Internet. Un poste central sert l'application à plusieurs postes de tatami via le réseau local, avec file d'attente par aire de compétition, journal d'audit par opérateur et sauvegarde automatique restaurable à chaud.

  • Architecture, modèle de données et API REST documentés
  • Migrations de base de données versionnées, tests automatisés, CI GitHub Actions
  • Livré en exécutable autonome, avec guide d'installation et guide utilisateur
